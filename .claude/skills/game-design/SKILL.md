# Référentiel game design

Ce skill donne accès à une base de fiches de game design en français, rédigées pour être lues par un agent pendant le développement d'un jeu.

## Où sont les fiches

La racine du référentiel est le dépôt qui contient ce fichier : trois niveaux au-dessus (`.claude/skills/game-design/SKILL.md` → racine). Commence par lire `CLAUDE.md` à cette racine : il contient la **table de routage** qui indique quelle fiche lire selon la tâche.

## Marche à suivre

1. Identifie la tâche (ex. « implémenter un saut », « équilibrer des armes », « concevoir le premier niveau »).
2. Ouvre `CLAUDE.md` à la racine du référentiel et repère la ou les fiches correspondantes (une à trois suffisent en général). S'il y a un genre clair, la fiche du dossier `genres/` est un bon point d'entrée.
3. Lis les sections utiles de la fiche : règles concrètes, valeurs de départ, pièges, checklist.
4. Applique-les au projet en cours **en respectant ses décisions existantes** (GDD, piliers, code déjà en place) : le projet prime sur le référentiel.
5. Expose les valeurs chiffrées comme paramètres réglables, et mentionne la fiche utilisée dans ta proposition.
